# Done criteria

A task is done only when:

- goal/scope/verification are recorded;
- root cause or design rationale is explicit;
- implementation is limited to intended paths;
- tests/linters or an equivalent oracle passed;
- docs/status/daily are updated when behavior or process changed;
- git status is understood and own changes are committed;
- production/live claims are backed by a live observation, not by a commit alone.
